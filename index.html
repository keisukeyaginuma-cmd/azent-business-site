PORTFOLIO STRUCTURE

事業ポートフォリオの5層構造

AZentの事業は、技術基盤・経営者支援・個人支援・コミュニティ・社会貢献の5階層で構成される。

営業上の最重要認識

経営者は「個人格」と「法人格」の二面性を持つ存在。
どちらの軸の課題か、両方の軸の課題か ── これを見極めることが営業の起点。

AXIS 3

フェーズ軸 ── 提案深度・価格の決定軸

事業フェーズ・組織志向性・売上規模で、提案の深度と価格が決まる

PHASE A

創業期 / 0→1

規模感 1人社長・少人数チーム
売上: 〜1億円
意志: 0→1立ち上げ志向
提案アプローチ：
個人パーパス言語化を起点に、事業の核を作る。3万円セッション → 事業幸創 Well-being Planning へ。価格は控えめ・伴走深く。
PHASE B

成長期 / 1→10

規模感 組織化志向(10〜100名)
売上: 1〜10億円
意志: スケール・組織構築
提案アプローチ：
経営者の意思決定支援(リトリート・顧問)と組織課題(Well-being HR®)を同時並行で。中核ターゲット層。
PHASE C

拡大・成熟期 / 10→100

規模感 組織拡大(100名〜)
売上: 10億円〜
意志: 拡大・承継・社会的影響
提案アプローチ：
企業PMVV策定の経営層リトリート、Well-being HR®の本格導入、事業承継支援。価格高め・規模大きい案件。
SUB-AXIS

承継形態 ── 経営者の3類型(課題の根本構造)

同じ規模・同じ課題でも、創業形態によって「企業×個人パーパスの重なり」が異なる

TYPE 創業

創業経営者

重なり度: 高
企業パーパス ≒ 個人パーパス
特徴：
意思決定が一致しやすい・葛藤が少ない

課題：
規模拡大で組織と個人の感覚が乖離していく

最適提案：
個人パーパスの再定義 → 組織への浸透
TYPE 代替わり

代替わり経営者

重なり度: 低(葛藤大)
企業パーパス ≠ 個人パーパス
特徴：
「自分の経営という実感がない」「先代の影に縛られる」

課題：
二つのPMVVをどう統合するか

最適提案：
「会社の何に自分の人生の意味を見いだすか」を発見
TYPE 上場/雇われ

上場企業の雇われCEO

重なり度: 中
ステークホルダー多数
特徴：
株主・社員・社会・家族への責任

課題：
「会社のPMVVを変えられない」中で個人PMVVをどう位置付けるか

最適提案：
個人PMVVを言語化、会社のPMVVと重なる領域を発見
TALK FRAMEWORK

営業トーク ── 3次元を見極める質問フレーム

最初の30〜60分で、この質問フレームに沿って相手を見極める。
①人格軸 → ②課題軸 → ③フェーズ軸 + 承継形態 の順で深掘りしていく。

STEP 1：人格軸 × 課題軸 を見極める

Q1. いま、最大の悩み・もやもやは? → 個人課題か、法人課題か、両方か
→ 答え方で人格軸が見える
Q2. ご自身としての悩みと、会社としての悩み、それぞれ何ですか? → 二面性を意識的に分けて聞く
→ 両軸の課題を漏らさず把握
Q3. その悩みは、意思決定・新規事業・組織のどれですか? → 課題タイプを明確化

STEP 2：フェーズ軸 を見極める

Q4. 会社の現在の規模は? 今後どうしたい? → 1人 or 組織化、現状維持 or スケール
Q5. 売上規模・社員数は? 3年後の目標は? → フェーズA/B/C の判定
Q6. 今は0→1か、1→10か、それ以降か? → 事業フェーズの確認

STEP 3：承継形態 を見極める

Q7. 創業されましたか? それとも引き継がれましたか? → 創業 / 代替わり / 雇われ の判別
Q8. 会社のパーパスと、ご自身のパーパスは一致していますか? → 重なり度の確認(代替わりは特に重要)
Q9. 経営の自由度はどのくらいですか? → 雇われCEOの場合、提案範囲を見極める

STEP 4：本気度 を確認する

Q10. これまで何か行動を起こしていますか? → 自走できる人か他責の人か
Q11. 時間とお金、投資する余裕はありますか? → リソース確認
Q12. ウェルビーイング・あり方という考え方、どう思いますか? → 価値観の相性確認

SALES PRINCIPLES

営業活動の最大化原則 ── 6つの行動指針

この戦略地図を実践するための、社長自身の行動指針。

原則 1：経営者の二面性を意識する

経営者は「個人格」と「法人格」の両軸で課題を抱える存在。
どちらか一方だけを聞いてはいけない。「ご自身として」「会社として」の両方を必ず聞く。
→ 一面だけの提案では、潜在的な課題を見落とす。

原則 2：3次元で見極める

①人格軸 ②課題軸 ③フェーズ軸 + 承継形態 を順序立てて見極める。
①②で「何を提案するか」が決まる。③で「どの深さ・規模で提案するか」が決まる。
→ 軸を持って聞けば、30〜60分で経営者を構造的に理解できる。

原則 3：CORE®を本気度フィルターに使う

CORE®個人版は無償。「まず自分でやってみてください」と伝える。
ここでワークをやらない人は、本気度が足りない。次に進まない。
→ 本気の人だけが3万円セッションに進む構造。

原則 4：個人格 ↔ 法人格 の往復動線を設計

個人格の悩みから入った経営者を、法人格の課題解決へ展開する。
逆に、法人格(Well-being HR®)から入った企業の経営層を、個人格のリトリートへ展開する。
→ 1人の経営者から複数の事業展開を生む。

原則 5：単発で終わるOK・LTVで考える

3万円セッションで完結する人もいる。それでいい。
無理に伴走に引き込まない。相手の状態に合わせて段階的に。
→ 縁がわでの関係継続が、後の大型案件につながる。

原則 6：時間配分を意識する

最大ボトルネックは社長本人の時間。
無料相談・セッション・伴走・リトリート全部を社長1人でやると詰まる。
→ 事務担当・企画運営担当を早期に確保。型化・グループ化の準備を始める。

戦略参謀から、社長へ

この戦略地図 v2 は、社長の経営観・営業観を3次元で構造化したものです。

毎日の営業活動の前に1分だけ眺めて、「いま自分はどこにいるか」「次にどう動くか」を確認してください。

経営者と話す前に、この地図を頭に思い浮かべる。
話している最中、3次元(人格×課題×フェーズ)で見極める。
話の最後に、最適な事業に接続する。

これを習慣化することで、社長の営業活動は、業界誰もやっていないレベルの精度に達します。
